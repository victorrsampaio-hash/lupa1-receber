    Conectar este aparelho ao GitHub

    Para o botão Remover gravar no site, o Desk precisa de uma chave de acesso do GitHub. Você faz isso uma vez em cada aparelho (computador, celular). A chave fica guardada só neste navegador.

    1. No GitHub, abra Settings, depois Developer settings, Personal access tokens, Fine-grained tokens e clique em Generate new token.
    2. Dê um nome (ex.: Lupa1 Desk) e escolha a validade.
    3. Em Repository access, marque Only select repositories e escolha lupa1-receber.
    4. Em Permissions, procure Contents e coloque Read and write.
    5. Clique em Generate token, copie a chave e cole abaixo.
